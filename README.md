# FONTX — Futuristic Unicode Style Generator & Symbol Vault

FONTX ek high-performance, futuristic Fancy Text Generator aur Symbol Vault Web Application hai jo pure HTML, CSS aur Vanilla JavaScript me bani hai. Isme kisi backend, API, React ya external library ki zarurat nahi hai.

---

## 🚀 Features Overview

- **300+ Unique Unicode Styles**: Generates 300+ distinct text transformations locally in your browser.
- **Symbol Vault**: Interactive collection of Gaming, Aesthetic, Arrows, Hearts, and Stars symbols.
- **Batch DOM Rendering**: Low-end phones par Smooth performance ke liye 24-by-24 results load hote hain.
- **Copy & Favorite System**: One-tap copy with clipboard fallback and localStorage Favorites memory.
- **Scanline Intro Animation**: 1.5 seconds futuristic scanline animation.
- **Futuristic Dark Design**: Pure black background, white typography, subtle neon accenting, and animated borders.
- **Mobile First & Zero Network**: 100% responsive and offline functional after initial load.

## 🌐 GitHub Pages Par Deploy Karne Ka Tarika (Step-by-Step)

### Step 1: GitHub Repository Banao
1. [GitHub.com](https://github.com) par login karo.
2. Top-Right '+' icon par click karke **New repository** choose karo.
3. Repository Name me **`FONTX`** rakho.
4. Repository ko **Public** select karo aur **Create repository** button par click karo.

### Step 2: Files Upload Karo
1. Repository page par **"uploading an existing file"** link par click karo.
2. Ye saari **5 Files** upload karo:
   - `index.html`
   - `style.css`
   - `fonts.js`
   - `script.js`
   - `README.md`
3. Commit changes button par click kardo.

### Step 3: GitHub Pages Enable Karo
1. Repository ki **Settings** tab par click karo.
2. Left sidebar menu me **Pages** option select karo.
3. Source ko **`Deploy from a branch`** set karo.
4. Branch me **`main`** aur folder me **`/ (root)`** select karke **Save** kardo.

### Step 4: Website Live!
1. 1–2 minutes wait karne par aapka live website link mil jayega (e.g. `https://your-username.github.io/FONTX/`).
